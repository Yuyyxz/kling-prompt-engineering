# Director Engine 评分标准（Rubric）

每项 0 或 1 分，满分 10 分。通过线：**7/10**。

## 评分项

| # | 维度 | 判定标准 |
|---|------|----------|
| 1 | 导演五问 | 回答了至少「功能」+「视角」两问，且用动词/名词描述而非形容词堆砌 |
| 2 | 可见节拍 | 包含至少一个具体的、可被摄影机捕捉的动作或状态变化（如"手从画面右侧伸入"） |
| 3 | 具体光源 | 指定了真实光源（如"窗外北向自然光""头顶钨丝灯"），而非泛化的 "cinematic lighting" |
| 4 | 镜头运动 | 有明确的运镜指令（push-in / pan-left / crane-down 等）或明确标注 static |
| 5 | 声音意图 | 包含声音/音乐/音效描述（如"环境白噪音渐弱""低频弦乐铺底"） |
| 6 | 约束槽 | 有排除项声明（如 "No text, no logos, no watermark"） |
| 7 | Anti-slop | 未出现 cinematic / beautiful / 4k / epic / masterpiece / stunning / breathtaking 等空洞修饰词 |
| 8 | 一镜一拍 | 一个镜头 = 一个节拍 = 一个变化；未在同一镜头内塞入多个无关动作 |
| 9 | 格式规范 | 使用了时间轴格式（0:00-0:03 ...）或标准公式（主体+动作+环境+镜头+光+声音） |
| 10 | 可灵适配 | 考虑了可灵平台限制：时长选择合理（5s/10s/15s）、避免要求文字渲染、避免多主体同时复杂运动 |

## 阈值

- **Pass**: 总分 >= 7
- **Fail**: 总分 < 7

## 使用方式

评分时，将生成的 prompt 逐条对照上表。每条满足即给 1 分，不满足给 0 分。
不允许 0.5 分——要么满足，要么不满足。
