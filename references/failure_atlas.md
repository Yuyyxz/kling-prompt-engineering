## 8 大类问题

### 1. 镜头问题 (Camera Issues)

#### 镜头模糊
- **症状：** 画面模糊、不清晰、失焦
- **原因：** 提示词中没有明确焦点、景深设置不当
- **解决方案：**
  - 明确指定焦点：'焦点在主体面部'
  - 使用浅景深：'浅景深，背景虚化'
  - 避免快速运动：'缓慢推进'

#### 镜头抖动
- **症状：** 画面晃动、不稳定、抖动
- **原因：** 手持拍摄、运动过快
- **解决方案：**
  - 使用稳定器：'稳定器跟拍'
  - 减少运动幅度：'缓慢移动'
  - 使用固定镜头：'固定机位'

#### 镜头角度不当
- **症状：** 角度奇怪、视角不适、构图不佳
- **原因：** 角度描述不明确、角度选择不当
- **解决方案：**
  - 明确角度：'眼平角度'、'低角度'、'高角度'
  - 选择合适角度：根据意图选择
  - 避免极端角度：'避免极端俯仰'

### 2. 光影问题 (Lighting Issues)

#### 过曝
- **症状：** 画面太亮、细节丢失、高光溢出
- **原因：** 光线太强、没有阴影
- **解决方案：**
  - 降低光线强度：'柔和的光线'
  - 增加阴影：'侧光，营造层次'
  - 使用自然光：'自然光，避免过曝'

#### 欠曝
- **症状：** 画面太暗、细节不清、阴影太深
- **原因：** 光线不足、阴影太重
- **解决方案：**
  - 增加光线：'明亮的光线'
  - 减少阴影：'正面光，减少阴影'
  - 使用补光：'补光，提亮暗部'

#### 光影不自然
- **症状：** 光影奇怪、不真实、违和感
- **原因：** 光影描述不具体、光影矛盾
- **解决方案：**
  - 使用具体光源：'窗外的自然光'
  - 避免矛盾描述：'不要同时使用逆光和正面光'
  - 参考真实场景：'参考真实场景的光影'

### 3. 运动问题 (Motion Issues)

#### 动作不自然
- **症状：** 动作僵硬、不流畅、奇怪
- **原因：** 动作描述不具体、动作矛盾
- **解决方案：**
  - 使用具体动词：'缓慢转身'而非'移动'
  - 避免矛盾动作：'不要同时向前和向后'
  - 参考真实动作：'参考真实的人体动作'

#### 运动过快
- **症状：** 运动太快、看不清、眩晕
- **原因：** 运动速度描述不当
- **解决方案：**
  - 降低速度：'缓慢移动'
  - 使用慢动作：'慢动作'
  - 减少运动幅度：'小幅移动'

#### 运动不连贯
- **症状：** 动作跳跃、不连贯、突变
- **原因：** 动作描述不连续、缺少过渡
- **解决方案：**
  - 描述连续动作：'从A到B的连续动作'
  - 添加过渡：'缓慢过渡'
  - 避免突变：'避免突然变化'

### 4. 参考角色问题 (Reference Role Issues)

#### 角色变形
- **症状：** 面部变形、身体变形、比例失调
- **原因：** 参考图质量差、描述不具体
- **解决方案：**
  - 使用高质量参考图：'清晰的正面照'
  - 明确描述：'保持面部特征不变'
  - 减少运动：'减少面部区域的运动'

#### 角色不一致
- **症状：** 角色变化、不连贯、换人
- **原因：** 缺少参考图、描述不一致
- **解决方案：**
  - 使用参考图：'@image1 角色参考'
  - 保持描述一致：'使用相同的描述'
  - 减少变化：'保持角色特征不变'

#### 角色识别度低
- **症状：** 看不清、模糊、不明确
- **原因：** 参考图不清晰、描述太模糊
- **解决方案：**
  - 使用清晰参考图：'高分辨率的参考图'
  - 明确特征：'红色头发，蓝色眼睛'
  - 减少遮挡：'面部无遮挡'

### 5. 时长问题 (Duration Issues)

#### 视频太短

- **原因：** 时长设置太短、内容太多

  - 分段制作：'分多集制作'

#### 视频太长

- **原因：** 时长设置太长、内容太少
- **解决方案：**

  - 加快节奏：'加快节奏'

#### 节奏不当

- **原因：** 节奏描述不当

  - 参考示例：'参考类似视频的节奏'

## 诊断流程

1. **识别问题类型**：根据用户描述，识别问题属于哪个类别
2. **分析具体原因**：在该类别下，分析具体原因
3. **提供解决方案**：根据原因，提供具体的解决方案
4. **验证解决**：验证解决方案是否有效
