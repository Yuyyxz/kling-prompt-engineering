# Seedance 提示词实战指南

> 来源：即梦 Seedance 2.0 官方使用手册（飞书文档导出）+ seed.bytedance.com 公开资料
> 更新：2026-08-03

这不是 API 文档。这是"怎么写提示词才能让 Seedance 听懂你"的实操笔记。

---

## 核心交互方式：@引用

Seedance 用 `@素材名` 来指定每个素材的角色。不是标签语法，是自然语言里直接写。

```
@图片1 作为首帧，@视频1 参考镜头语言，@音频1 用于配乐
```

**写提示词的原则：** 把所参考的视频/图片/音频多次 @，并注明情绪、时序、各环节细节。素材多的时候，检查每个 @对象有没有标清楚——别把图、视频、角色搞混了。

---

## 两个入口，别走错

| 入口 | 何时用 | 限制 |
|------|--------|------|
| **首尾帧** | 只上传首帧图 + prompt | 不能加视频/音频参考 |
| **全能参考** | 多模态组合输入（图+视频+音频+文本） | 智能多帧和主体参考不可选 |

需要多模态组合？必须走全能参考。

## 提示词模板（按场景）

### 有首帧图 + 想参考视频动作

```
@图1为首帧，参考@视频1的打斗动作，[角色描述]在[场景]中[具体动作]。
保持动作连贯流畅，镜头跟随角色移动。
```

### 延长已有视频

```
将@视频1延长5s，[描述新增部分的内容和动作变化]。
保持画面风格、角色外观、光线方向与前段一致。
```

**注意：** 生成时长选"新增部分"的时长。延长 5s → 生成长度也选 5s。不是选总时长。

### 融合多个视频

```
我要在@视频1和@视频2之间加一个场景，内容为[描述过渡内容]。
保持两段视频的风格和色调统一。
```

### 没音频素材，参考视频里的声音

```
参考@视频1的环境音和节奏，生成[新内容描述]。
声音风格保持一致。
```

### 连续动作（多参考图）

```
角色从跳跃直接过渡到翻滚，保持动作连贯流畅。
@图1@图2@图3 为角色不同角度参考。
```

### 音乐卡点

```
@音频1为配乐，画面动作卡在节拍点上。
[描述每个节拍对应的画面变化]。
```

### 视频编辑（定向修改）

```
保持@视频1的整体内容不变，仅将[指定片段/角色/动作]替换为[新描述]。
其余画面、光线、节奏保持不变。
```

## Seedance 真正擅长的事（官方确认）

1. **一致性** — 人脸、服装、商品细节、小字、场景风格前后统一
2. **运镜/动作复刻** — 上传参考视频，模型复刻走位、运镜、复杂动作
3. **创意模板/特效复刻** — 转场、广告成片、电影片段、复杂剪辑都能"照着模仿"
4. **剧情补全** — 给个开头，模型能补全后续发展
5. **一镜到底** — 镜头连贯性强
6. **视频编辑** — 不重头生成，定向修改指定片段
7. **音乐卡点** — 画面动作对齐节拍
8. **情绪演绎** — 表情和肢体语言更到位
9. **音色还原** — 声音更真实

## 平台限制（必须知道）

| 限制 | 说明 | 绕过 |
|------|------|------|
| **写实人脸素材被拦截** | 上传含清晰可辨识人脸的图片/视频会被系统拦截，无法生成 | 用非写实风格（动画/3D/插画）；或用 AI 生成的虚构人脸 |
| **IP/品牌名屏蔽** | 提示词里不能出现受保护 IP 名称 | 用描述性语言替代："穿红色战甲的太空战士"而非"钢铁侠" |
| **复杂物理运动** | 极复杂的多体碰撞、流体仍有局限 | 简化动作；拆成多段 |
| **拥挤多主体** | 太多角色互相干扰 | 选一个主角，其余虚化/简化 |

## 提示词写法对比

**别这么写：**
```
生成一个很酷的视频，电影感，史诗级画面，4K超清
```

**这么写：**
```
@图1为首帧。黄昏的废弃工厂，一个穿黑色风衣的女人从阴影中走出。
参考@视频1的镜头推进节奏。
中景→近景，缓慢推进，手持微晃。
侧光从左侧破窗射入，暖色，光比大。
环境音：金属碰撞回响、远处风声。
保持角色面部和服装与@图1完全一致。
```

区别在哪？后者有：具体素材角色分配、可见动作、镜头运动、真实光源、声音、一致性锚定。前者是愿望。

## Seedance 2.5 新增（2026-07-31）

如果你用的是 2.5（通过即梦/豆包专业版），还有这些：

- **30 秒单次生成** — 不用再 10s 一截地接了
- **30 图 + 10 视频 + 10 音频** — 一次请求的参考上限
- **时间戳控制** — "0-5秒：[内容]；5-12秒：[内容]；12-30秒：[内容]"
- **Clay Render 参考** — 上传无纹理 3D 模型，引导空间布局、姿态、运动路径、光影方向
- **绿幕替换** — 直接替换背景
- **分段编辑** — 生成后改某几秒的角色/动作/声音，其余不动
