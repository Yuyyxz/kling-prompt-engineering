# 反向检查清单（Avoidance Checklist）

> 生成完了，感觉不对？对着这张表查。
>
> **定位：** 这是一个**调试工具**，不是 prompt 模板。可灵没有独立的负面提示词字段——你不可能在 prompt 里写"无模糊""无变形"来排除问题（否定会召唤，见 [09-反空话词典](../09-anti-slop.md)）。
>
> **正确用法：** 生成后对照检查 → 定位问题类型 → 用正向描述修复。
>
> **错误用法：** 把这份清单复制进 prompt。

---

## 怎么用

1. **生成完视频，感觉不对** → 按场景找到对应分类，逐条对照
2. **定位到问题** → 去 [失败诊断图谱](failure_atlas.md) 查修复方向
3. **用正向描述改写 prompt** → 不写"无 X"，写"应该是 Y"

**举例：** 对照发现"面部变形" → 不是加"无面部变形"，而是改 prompt："中景，锁定镜头，极慢推进，保持面部结构不变"。

---

## 按场景检查

### 1. 通用（每次必查）

| 检查项 | 正向修复方向 |
|--------|-------------|
| 画面模糊/噪点/失真 | 写具体材质描述和光线方向，不写"高清""清晰" |
| 过曝/欠曝 | 写光源方向和强度："窗户光从左侧射入，柔和漫射" |
| 裁切不当/主体偏移 | 写空间锚定："人物位于画面左侧三分之一处" |
| 背景杂乱 | 分三层写：前景 + 中景主体 + 背景虚化 |
| 动作僵硬/穿模 | 简化动作；一个镜头 = 一个动作节拍 |

### 2. 人物场景

| 检查项 | 正向修复方向 |
|--------|-------------|
| 面部变形 | 拉远到中景；锁定镜头或极慢推进 |
| 表情不自然 | 写具体表情动作："微微皱眉""嘴角上扬" |
| 手指畸形 | 藏手："双手自然放在桌面""手插口袋" |
| 肢体比例失调 | 避免极端角度；用中景而非远景 |
| 口型不同步 | 台词 ≤ 10 词 + 锁定镜头 + 减少头部转动 |

### 3. 产品/广告

| 检查项 | 正向修复方向 |
|--------|-------------|
| 产品变形/logo 失真 | 开头写"保持[产品]的[具体特征]完全不变" |
| 材质塑料感 | 写具体材质："磨砂玻璃""拉丝金属""哑光塑料" |
| 背景杂乱 | 干净背景 + 受控光线；产品占画面主体 |
| 版权/品牌冲突 | 不写真实品牌名；描述外观特征代替 |

### 4. 自然/风景

| 检查项 | 正向修复方向 |
|--------|-------------|
| 水面/雨滴/云层不自然 | 写运动方向："水面从左向右泛起涟漪" |
| 建筑变形/透视错误 | 写"建筑线条垂直，透视正常" |
| 运动不自然 | 用"自然""匀速"等速度词；指定物理方向 |

### 5. 动作/运动

| 检查项 | 正向修复方向 |
|--------|-------------|
| 动作僵硬/不连贯 | 用慢动作（0.5 倍速）给模型更多帧 |
| 动作过快/过慢 | 写明确速度词："匀速""缓慢""极慢" |
| 穿模/飘浮 | 简化物体交互；避免复杂物理接触 |

### 6. 口播/数字人

| 检查项 | 正向修复方向 |
|--------|-------------|
| 面部变形 | 中近景 + 锁定镜头 + 减少头部运动 |
| 口型不同步 | 短句 + 锁定镜头 + 正面光线 |
| 背景杂乱 | 简洁背景 + 受控光线 |
| 政治/宗教敏感 | 换中性描述；避开争议话题 |

## 附录：按问题类型速查

### A. 画质

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 模糊 | 具体材质 + 光线方向（不是"高清"） |
| 噪点 | "画面干净"或指定"低 ISO 质感" |
| 过曝/欠曝 | 光源方向 + 强度 + "面部曝光正常" |
| 色差 | 指定色温："暖色约 3200K"或"冷色约 5600K" |
| 压缩伪影/锯齿 | 通常是设置问题，不是 prompt 问题 |

### B. 构图

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 裁切不当 | 写裁切位置："胸部以上""膝盖以上" |
| 主体偏移 | 写空间位置："画面左侧三分之一处" |
| 背景杂乱 | 三层结构：前景 + 中景主体 + 背景虚化 |
| 地平线倾斜 | 写"地平线水平" |
| 主体太小/太大 | 指定景别 + 焦距 |

### C. 风格

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 风格不一致（多片段） | 每个片段引用相同的"风格圣经" |
| 色调冲突 | 统一指定一个色调方向 |
| 时代/文化错误 | 用建筑特征、服装细节代替地名 |
| 风格混杂 | 组合不超过两个风格（见 [20-风格标签](../20-style-tags.md)） |

### D. 动作

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 动作僵硬 | 一个物理原因 + 可见后果（不是多个舞台指导） |
| 速度异常 | 写明确速度词；一个镜头只一个速度 |
| 不连贯/矛盾 | 矛盾检查：所有速度词/方向词只留一个值 |
| 穿模/飘浮 | 简化交互；避免复杂物理接触 |

### E. 内容安全

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 生成被拒 | 换同义词；避开武器品牌/政治人物/具体暴力动作/版权角色名 |
| 擦边内容 | 模型过滤是宁杀勿纵的——擦边的也换掉 |

→ 完整替换表：[失败诊断图谱 §8](failure_atlas.md)

### F. 人物

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 面部变形 | 中景 + 慢动作/锁定镜头 |
| 表情不自然 | 写具体面部动作 |
| 手指畸形 | 藏手或简化手部动作 |
| 口型不同步 | 短句 + 锁定 + 少转头 |

### G. 自然/物理

| 症状 | 你该写什么（正向） |
|------|-------------------|
| 水面/流体异常 | 写运动方向 + "自然" |
| 建筑变形 | 写"线条垂直，透视正常" |
| 粒子消失 | 写生命周期："在空气中缓慢消散" |
