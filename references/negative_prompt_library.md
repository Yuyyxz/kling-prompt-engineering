# 负面提示词库 (Negative Prompt Library)
# 双索引：场景主索引 + 问题类型附录

## 概述

负面提示词是明确排除不需要的元素，确保生成的视频符合预期。

**使用方式：**
- **主索引（按场景）：** 用户只需选"我在拍什么"→ 直接复制对应区块 → 零思考
- **附录（按问题类型）：** 调试时查，了解具体问题

---

## 主索引：按场景分类

### 1. 通用（必加）

**适用场景：** 所有视频

```
避免：
- 画质：模糊、噪点、失真、过曝、欠曝、色差、压缩伪影、锯齿
- 构图：裁切不当、主体偏移、背景杂乱
- 动作：动作僵硬、动作不连贯、穿模
```

### 2. 人物场景

**适用场景：** 有人物的视频

```
避免：
- 通用：模糊、噪点、裁切不当、动作僵硬
- 人物：面部变形、表情不自然、肢体比例失调、手指数量错误
- 场景：背景杂乱、风格不一致
- 动作：动作僵硬、动作不连贯、穿模
```

### 3. 产品/广告

**适用场景：** 产品展示、品牌广告

```
避免：
- 通用：模糊、噪点、裁切不当
- 产品：产品变形、logo失真、材质塑料感
- 场景：背景杂乱、风格不一致
- 动作：动作僵硬、动作不连贯
- 内容：版权侵权、品牌冲突
```

### 4. 自然/风景

**适用场景：** 风景、城市、自然

```
避免：
- 通用：模糊、噪点、过曝、欠曝
- 自然：水面不自然、雨滴静止、云层重复
- 建筑：建筑变形、透视错误
- 动作：运动不自然、速度异常
```

### 5. 动作/运动

**适用场景：** 动作场景、运动视频

```
避免：
- 通用：模糊、噪点
- 动作：动作僵硬、动作过快、动作过慢、动作不连贯、动作矛盾
- 运动：运动模糊、穿模、飘浮
- 场景：背景杂乱、风格不一致
```

### 6. 口播/数字人

**适用场景：** 知识口播、数字人视频

```
避免：
- 通用：模糊、噪点
- 人物：面部变形、表情不自然、口型不同步
- 场景：背景杂乱、风格不一致
- 动作：动作僵硬、动作不连贯
- 内容：政治敏感、宗教冒犯
```

## 使用指南

### 1. 根据场景选择

根据视频类型选择对应的场景分类。

### 2. 组合使用

可以组合多个场景的负面提示词。

### 3. 适度使用

不要过度使用负面提示词，以免限制创意。

### 4. 测试调整

根据生成结果调整负面提示词。

### 5. 调试时查附录

当生成结果有问题时，查看附录找到具体问题类型。

---

## 约束条件

- 必须根据场景选择合适的负面提示词
- 不要过度使用负面提示词
- 根据生成结果调整负面提示词
- 保持负面提示词的简洁性
- 调试时查看附录找到具体问题
