# 负面提示词库 (Negative Prompt Library)
# 5 大场景分类的负面提示词

## 概述

负面提示词是明确排除不需要的元素，确保生成的视频符合预期。

## 5 大场景分类

### 1. 画质问题 (Quality Issues)

| 负面提示词 | 说明 | 使用场景 |
|------------|------|----------|
| 模糊 | 画面不清晰 | 所有场景 |
| 噪点 | 画面有噪点 | 所有场景 |
| 失真 | 画面失真 | 所有场景 |
| 过曝 | 画面太亮 | 所有场景 |
| 欠曝 | 画面太暗 | 所有场景 |
| 色差 | 颜色不准确 | 所有场景 |
| 压缩伪影 | 压缩导致的画质损失 | 所有场景 |
| 锯齿 | 边缘有锯齿 | 所有场景 |

**使用示例：**
```
避免：模糊、噪点、失真、过曝、欠曝、色差、压缩伪影、锯齿
```

| 主体太大 | 主体在画面中占比太大 | 所有场景 |

**使用示例：**

## 使用指南

### 1. 根据场景选择

根据视频类型选择对应的负面提示词分类。

### 2. 组合使用

可以组合多个分类的负面提示词。

### 3. 适度使用

不要过度使用负面提示词，以免限制创意。

### 4. 测试调整

根据生成结果调整负面提示词。

## 约束条件

- 必须根据场景选择合适的负面提示词
- 不要过度使用负面提示词
- 根据生成结果调整负面提示词
- 保持负面提示词的简洁性
