# 分镜转 Prompt 工作流

> 分镜板（Beat Board）画完了，接下来是把它变成模型能吃的 prompt。这步做不好，前面所有导演思考全白费。

---

## 输入格式：Beat Board

每个分镜格子应该包含这些信息：

```
Shot 01 | 中近景 | 3s
画面：穿白衬衫的女人站在窗边，右手食指轻触玻璃。窗外是灰色城市天际线，阴天。
动作：视线从窗外收回，缓慢转身看向房间内。
情绪：犹豫→决断
声音：安静房间音，指尖触玻璃一声轻响。
```

不是所有字段都有。有些格子可能没有声音，有些没有明确情绪。但**画面**和**动作**必须有——没有这两个，这格分镜不存在。

---

## 逐字段翻译规则

### 画面 → prompt 的场景描述

分镜里的"画面"是给人看的简写。翻译成 prompt 时要补全模型需要的细节。

**补什么：**
- 光线来源和方向（分镜通常不写光，但模型需要）
- 材质和质感（"衬衫"→"白色棉质衬衫，袖口卷至肘部"）
- 空间关系（"站在窗边"→"站在落地窗左侧三分之一处"）

**不补什么：**
- 情绪形容词（"忧郁的"→删掉。用光线和姿态表达）
- 镜头效果形容词（"电影感的"→删掉。用相机型号和镜头焦距表达）

### 动作 → prompt 的运动描述

分镜写的动作通常是概括性的。翻译时要精确到可执行。

**原则：一个 beat 一个动作。** 5 秒的镜头里塞三个动作，模型会糊。

```
分镜写的：她转身走向桌子
prompt 写的：她从窗边转身，走三步，在桌前停下
```

"走三步"比"走向"更精确——模型知道什么时候该停。

### 景别 → 镜头约束

分镜标注的景别直接映射为 prompt 的镜头约束：

| 分镜标注 | prompt 写法 | 补充说明 |
|---------|------------|---------|
| 远景 | 锁定远景，无重新构图 | 别加推进——远景推进没意义 |
| 全景 | 锁定全景 | 人物全身在画面内 |
| 中景 | 锁定中景 | 膝盖以上 |
| 中近景 | 锁定中近景 | 胸部以上 |
| 近景 | 锁定近景 | 面部+肩部 |
| 特写 | 锁定特写 | 局部细节 |

**"锁定"两个字很重要。** 不写锁定，模型会自由重新构图——一构图就漂移。

### 时长 → 节奏控制

分镜标注的时长决定 prompt 里动作的密度。

- **3 秒以内：** 一个微动作。眨眼、转头、手指动一下。够了。
- **5 秒：** 一个完整动作。起身、走两步、停下。
- **10 秒：** 一个动作 + 一个变化（光线变、天气变、背景里某个东西动了）。
- **超过 10 秒：** 考虑拆成两段。单段太长，一致性难保。

### 情绪 → 用光线和姿态翻译

**永远不要在 prompt 里写情绪词。** 分镜里写"犹豫→决断"是给人看的。prompt 里要写成可被摄影机拍到的东西：

```
情绪：犹豫→决断
↓ 翻译成
视线从窗外收回（犹豫的结束），下巴微抬，肩膀从放松变为收紧（决断的物理表现）
```

光线也跟着变。犹豫是冷光——窗光偏蓝。决断是暖光——她转身时台灯的光照到脸上。

### 声音 → 音画对齐

分镜里的声音描述直接翻译，但要用时间锚点对齐：

```
分镜：安静房间音，指尖触玻璃一声轻响
prompt：声音：安静房间音。[0s] 指尖触玻璃一声轻响。
```

如果分镜没写声音，按空间默认补：
- 室内 → 安静房间音
- 室外城市 → 远处车流+近处人声
- 室外自然 → 风声+鸟鸣（具体到什么鸟）
- 水下 → 低频闷响+气泡声

## 角色卡复用

分镜里同一个角色出现多次，每次翻译 prompt 时从角色卡复制完整外貌描述，逐字一致。

### 角色卡格式

```
【角色卡 - 女主角】
面部：椭圆脸，杏仁眼，挺直鼻梁，薄唇，自然肤色
发型：黑色及肩直发，左侧别一枚银色发夹
服装：白色棉质衬衫，袖口卷至肘部，深蓝色高腰牛仔裤
体型：165cm，偏瘦，体态端正
```

### 复用规则

1. **每段 prompt 第一行** — 从角色卡复制完整描述，一个字不改
2. **即使分镜里没画细节** — 分镜可能只画了"白衬衫女人"，但 prompt 要写全
3. **跨镜头一致** — Shot 01 和 Shot 05 用的是同一张角色卡，描述必须逐字相同
4. **I2V 时搭配参考图** — 角色卡管文字描述，参考图管视觉锚定，双保险

## 风格 token 统一

多镜头之间要保持视觉一致性。方法是定义一组风格 token，所有镜头的 prompt 共享。

### 风格 token 定义

```
【风格 Token 组 - 都市孤独】
相机：Sony Venice 拍摄
镜头：85mm f/1.4
色调：冷蓝灰基调，暖色只在点光源出现
质感：浅景深，背景奶油般化开，前景偶尔有遮挡物虚化
颗粒：细颗粒感，不过度
```

### 使用方式

每个镜头的 prompt 末尾追加风格 token 组。逐字一致，不改一个字母。

```
Shot 01 prompt：
[场景描述]。[动作]。[镜头约束]。[光线]。[声音]。
Sony Venice 拍摄，85mm f/1.4，冷蓝灰基调，暖色只在点光源出现，
浅景深，背景奶油般化开，细颗粒感。

Shot 02 prompt：
[场景描述]。[动作]。[镜头约束]。[光线]。[声音]。
Sony Venice 拍摄，85mm f/1.4，冷蓝灰基调，暖色只在点光源出现，
浅景深，背景奶油般化开，细颗粒感。
```

**为什么逐字一致？** 模型对措辞变化极度敏感。"冷蓝灰基调"和"偏蓝偏灰的色调"在模型眼里是两个东西。复制粘贴，别发挥。

## 输出格式

翻译完成的 prompt 应该长这样：

```

═══════════════════════════════════════
保持画面中人物的面部、发型、衣装和背景构图不变。
她从窗边转身，走两步，在房间中央停下。
镜头：锁定中近景，无重新构图。
光线：冷色窗光从右侧照射，她转身时面部逐渐进入暖色台灯光区。

浅景深，背景奶油般化开，细颗粒感。

═══════════════════════════════════════
```

每个 shot 独立成块，包含完整信息。拿去直接喂给模型，不用再翻译。

## 翻译示例：3 镜头分镜 → 3 段 prompt

### 输入分镜

```
Shot 01 | 远景 | 5s
画面：清晨，空旷的混凝土广场。一个穿黑色长风衣的人站在广场正中央。
动作：静止不动，只有风衣下摆被风吹动。
情绪：孤独、渺小

Shot 02 | 中景 | 5s
画面：同一个人，镜头推近到膝盖以上。能看到他低着头，双手插在风衣口袋里。
动作：缓慢抬头，视线从地面移到远方的建筑。
情绪：从内省到关注

Shot 03 | 近景 | 3s
画面：面部近景。风吹乱了他的头发。
动作：微微眯眼，嘴角几乎不可见地上扬。
情绪：决断
```

### 角色卡

```
【角色卡 - 男主角】
面部：方形下颌，深眼窝，浓眉，薄唇，小麦色肤色
发型：深棕色短发，自然微卷，被风吹时凌乱
服装：黑色长款羊毛风衣，内搭深灰色高领毛衣，黑色直筒西裤
体型：180cm，偏瘦，站姿笔挺
```

### 风格 Token 组

```
【风格 Token 组 - 混凝土广场】
相机：ARRI Alexa Mini 拍摄
镜头：Cooke S7/i 系列
色调：低饱和，混凝土灰+天空灰白+黑色服装，无暖色
质感：深景深（远景/中景），浅景深（近景），细颗粒感
氛围：冷，安静，秩序感
```

### 翻译结果

```
风衣下摆被微风持续吹动，是画面中唯一的运动。

风衣下摆继续被微风吹动。
镜头：锁定中景（膝盖以上），缓慢推进至腰部以上。
光线：同一灰白天空漫射光，无方向变化。
声音：远处低频风声。[2s] 衣物摩擦声（抬头的身体动作）。

无暖色，浅景深，背景奶油般化开，细颗粒感，冷，安静，秩序感。
约束：不改变身份、服装、背景布局或运动节奏。

═══════════════════════════════════════

═══════════════════════════════════════

风吹乱他的头发，几缕发丝遮住半边眉毛。
他微微眯眼，嘴角几乎不可见地上扬——不是微笑，是决定。
镜头：锁定近景（面部+肩部），固定机位。
光线：同一灰白天空漫射光，面部无阴影，均匀柔光。
声音：安静。[1s] 一声极轻的鼻息。
```

注意看：风格 token 组在三段 prompt 里逐字一致。角色描述从同一张卡复制。镜头约束和分镜景别一一对应。

## 质量检查清单

翻译完每一段 prompt，过一遍这个清单：

### 基础检查

- [ ] 每个 shot 都有完整的画面描述（不是只写了动作）
- [ ] 每个 shot 都有镜头约束（锁定 + 景别）
- [ ] 每个 shot 都有光线描述（不能空着）
- [ ] 每个 shot 都有声音描述（没写就按空间默认补）
- [ ] 没有情绪形容词（"悲伤的""紧张的"全删了）

### 一致性检查

- [ ] 同一角色跨镜头的外貌描述逐字一致（从角色卡复制）
- [ ] 风格 token 组跨镜头逐字一致（复制粘贴，没改过）
- [ ] 光线连续性——上一个 shot 的光源方向和色温，下一个 shot 能接上
- [ ] 空间连续性——上一个 shot 的背景元素，下一个 shot 还在

### 执行检查

- [ ] 每个 5 秒 shot 只有一个完整动作
- [ ] 没有"先做 A 再做 B 然后做 C"的三段式动作
- [ ] I2V shot 都标注了挂哪张参考图
- [ ] 续写 shot 的第一行是"保持 XX 不变"
- [ ] 时长超过 10 秒的 shot 已考虑拆分

### 模型适配检查

- [ ] prompt 长度匹配目标模型（Kolors ≤150 字 / Qwen 可以长 / Seedream 按 7 要素）
- [ ] 语言策略正确（场景中文 / 技术词英文）
- [ ] 负面提示词按模型格式提交（独立参数 / 约束行）

## 常见翻车和修复

| 翻车 | 原因 | 修复 |
|------|------|------|
| 角色跨镜头长得不一样 | 每次 prompt 里角色描述措辞不同 | 建角色卡，逐字复制 |
| 色调跳跃——上个镜头冷蓝下个暖黄 | 风格 token 没统一 | 定义风格 token 组，逐字追加 |
| 动作糊成一团 | 一个 shot 里塞了太多动作 | 砍到只剩一个 |
| 镜头乱跳 | 没写"锁定" | 每个 shot 加"锁定 + 景别" |
| 续写时人物突然换衣服 | 续写 prompt 重新描述了外观 | 续写只写"保持 XX 不变"+变化部分 |
| 声音和画面不同步 | 没用时间锚点 | 用 `[Xs]` 标记音效出现的时间点 |
