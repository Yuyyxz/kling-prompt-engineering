# 中文社区竞品调研报告：AI 视频 Prompt 生态

> 调研时间：2026-08-06 | 调研人：Hermes Agent
> 调研范围：B 站 / 知乎 / 小红书 / 阿里云官方文档 / GitHub 中文 AI 视频 skill
> 目的：摸清中文社区 AI 视频 prompt 教学生态，找出 KPE 的差异化位置与可吸收的实战方法。

---

## 一、生态全景

中文 AI 视频 prompt 教学内容可以分成四层：

| 层级 | 代表 | 特征 | 深度 |
|------|------|------|------|
| 官方文档 | 阿里云百炼（Vidu/万相）、可灵官方 | 提示词公式 + 词典 + 调优案例 | 中，重功能不重方法论 |
| B 站头部 UP | Mx-Shell（百万播放）、可灵 3.0 保姆级教程 | 案例驱动，先给成品再拆方法 | 中高，偏实操 |
| 图文平台 | 知乎、号令天下、人人都是产品经理 | 单篇技巧贴，经验分享 | 中低，不成体系 |
| GitHub 中文 skill | Wayhhow/ai-video-shot-prompt-skill | 把方法论封装成 Agent Skill | 高，可复用 |

## 二、重点竞品拆解

### 1. Mx-Shell（刘紫鱼）——《丧尸清道夫》创作方法

- **背景：** B 站百万播放 UP，在《丧尸清道夫》创作分享中公开了"三大部分框架"，被封装成 GitHub skill（Wayhhow 项目）
- **核心方法——三大部分框架：**
  1. **【基础设定】** 时间 / 地点 / 人物 / 参考图描述 / 声音限制
  2. **【氛围画质】** 风格核心 / 去 AI 味 / 限制词 / 视觉基调 / 色彩影调
  3. **【画面内容】** 分镜 / 景别 / 构图 / 运镜 / 故事内容（怎么做 → 为什么 → 效果）
- **顺序敏感：** 先锚人/地/时 → 再定调 → 最后讲故事。实测"AI 对提示词前段注意力权重更高"，风格/限制词放中段避免污染基础设定
- **去 AI 味三痛点：** 塑料感（人物僵硬磨皮）→ 强制"超写实/真人实景拍摄/电影动作捕捉"；游戏 CG 感（镜头漂移）→ 显式"杜绝游戏CG感/动作僵硬"；叙事平 → "怎么做/为什么/效果"三段式动作描述法
- **验证数据：** "用本 skill 写，平均减少 60% 塑料感和 80% 动作崩坏抽卡次数"

### 2. 阿里云官方（Vidu / 万相）提示词指南

- **提示词公式体系（比 B 站更结构化）：**
  - 基础公式：主体 + 场景 + 运动
  - 进阶公式：主体（主体描述）+ 场景（场景描述）+ 运动（运动描述）+ 美学控制 + 风格化
  - 图生视频公式：运动 + 运镜（图已定主体/场景/风格）
  - 声音公式（wan2.7）：主体 + 场景 + 运动 + 声音描述（人声/音效/BGM 三类）
  - 多镜头公式：总体描述 + 镜头序号 + 时间戳 + 分镜内容
- **提示词词典：** 运镜/景别/视角/构图/风格/特效/氛围 7 大类触发词（如"大动态"触发运动幅度）
- **调优方法论：** 首版不理想 → 针对性修改（如"火车倒着开"→ 用主体与背景的大小比例关系营造运动方向）

### 3. 号令天下（公众号风格）——四条"硬功夫"

- **先给提纲再写正文：** 绝对化指令框死（只输出提纲/禁止完整句子/不解释）
- **先提问再生成：** "请先向我提出 3 个关键问题" + 每个问题聚焦一个变量 + 给选项锚点
- **五层嵌套分镜：** 画面基底 + 旁白 + 节奏动作（含触发条件与结果）+ "下一镜："强制分隔 + 音效
- **首尾帧写死静态特征：** 服装纹理走向/发型分线/配饰反光点数量/液体弧度与水珠颗数——尾帧 100% 复用首帧静态描述，仅改动能部分

### 4. 人人都是产品经理 / 今日头条

- **小红书批量起号流程：** AI + 内容生成视频 → 批量素材 → 快速起号
- 强调"副业变现"路径，非方法论

## 三、KPE 与它们的对比

| 维度 | B 站/知乎（经验流） | 阿里官方（功能流） | **KPE（方法论流）** |
|------|-------------------|-------------------|-------------------|
| 体系化 | 单篇技巧，不成体系 | 公式+词典，无导演思维 | **24 文件分层 + 交叉引用** |
| 导演思维 | 少 | 无 | **导演五问 + 意图导向** |
| 反空话 | 散见（Mx-Shell 有"去AI味"） | 官方词典无此概念 | **Anti-Slop 完整体系** |
| 声音设计 | 少 | 有声音公式 | **音画三层模型** |
| 多模型适配 | 单平台 | 单平台 | **适配层（Kolors/Qwen/Seedream）** |
| 可验证 | 无 | 官方调优案例 | **evals 评估框架** |

**KPE 的差异化：** 中文可灵方法论 + 导演思维系统化——在"中文 + 可灵专用 + 导演思维"这个交叉点依然几乎空白。官方文档只有功能说明没有方法论；B 站/知乎是经验碎片；Mx-Shell 有方法论但聚焦单一风格（原子朋克丧尸）。

## 四、可吸收的实战方法（取长补短）

1. **「先提问再生成」交互模式**（号令天下）→ 可加入 KPE 的 workflows：用户意图不清晰时，先问 3 个关键问题再生成
2. **「首尾帧写死静态特征」**（号令天下）→ KPE 23 号已有"锁定身份约束"，但可补充"物理细节写死"的粒度：配饰反光点数量、液体水珠颗数
3. **「三大部分框架」的顺序敏感理论**（Mx-Shell）→ KPE 22 号已有"结构公式"（景别→主体→姿态→场景→光线→风格），可交叉引用 Mx-Shell 的"风格放中段避免污染基础设定"
4. **「怎么做/为什么/效果」动作描述法**（Mx-Shell）→ 可补充进 KPE 的动作描述方法论
5. **官方词典的"触发词"体系**（阿里 Vidu）→ KPE 19-cinematography-dictionary 可补充 Vidu 特有的触发词（大动态/中动态/小动态）

## 五、风险与应对

- **可灵模型迭代快：** 官方功能月更，内容可能过时 → KPE 已有对策：23 号首尾帧、21 号重试协议都是"模型无关"的方法论，版本迭代影响小
- **B 站"副业变现"用户画像：** 大多数用户要"怎么让视频不像 AI 生成的"而非"导演思维" → KPE 的 Anti-Slop + 反塑料感正好命中这个需求，但 marketing 语言可以往"去 AI 味"倾斜
- **官方文档免费且权威：** 阿里/可灵官方指南是最大潜在替代品 → KPE 的护城河是"方法论深度 + 导演思维 + 跨模型适配"，这些官方不提供

---

## 结论

中文 AI 视频 prompt 生态处于"官方给公式、社区给技巧、无人给体系"的阶段。KPE 是少有的"方法论 + 工具链 + 评估"三合一的系统化项目。最值得吸收的三个点：**Mx-Shell 的顺序敏感理论、号令天下的首尾帧写死粒度、阿里官方词典的触发词体系**。
