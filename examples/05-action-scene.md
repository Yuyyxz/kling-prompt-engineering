# 案例 5：动作场景（跟随式 + 时间轴语法）

## 场景

一个滑板少年在黄昏的城市街道滑行，镜头从侧面跟随——重点是速度感和动作节奏。

## Prompt

```
一个穿宽松黑色 T 恤的少年踩着滑板在黄昏的城市街道上滑行，轮子碾过地面接缝处溅起细小碎石。
镜头：侧面稳定器跟拍，与滑板保持同一速度，距离一臂，从腰部高度拍摄。背景中路灯和建筑向身后匀速掠过。
光线：夕阳从正前方低角度照射，少年身上形成暖色轮廓光，滑板在地面投出拉长的影子。

状态层：
从少年正常滑行开始（匀速），经过一段下坡时加速（身体重心前倾，T 恤被风鼓起），
结束于一个减速抬头的动作——前轮离地，后轮刹车，滑板在地面擦出一道弧线。

运动层：
滑行速度：匀速 → 下坡加速 → 突然减速（缓出到静止）。
镜头跟随速度同步变化。
少年身体：直立 → 前倾 15 度 → 后仰抬头。

节奏层：▂▃▅▇▁（渐进后急停）
[0s-2s] 匀速滑行，节奏平稳。轮子碾过地面的持续"嗡嗡"声。
[2s-3s] 下坡加速，风声变大，T 恤布料拍打声。
[3s-4s] 速度达到最快，轮子在地面的声音变尖锐。
[4s-5s] 突然减速——后轮擦地的"嘶——"声，碎石弹起，结束于安静。

声音：
- 环境音层：城市黄昏底噪——远处车流、一个路口的红绿灯提示音、微风。
- 动作音效层：[0s-2s] 轮子匀速碾过地面的低沉"嗡嗡" → [2s-3s] 风声渐强 + 布料拍打 → [3s-4s] 轮子声变高频 → [4s-5s] 后轮擦地的尖锐刹车声 + 碎石弹射声 → [5s] 安静，只有轮子最后转两圈的"嗒嗒"声。
- 情绪音乐层：无。滑板的声音本身就是节奏。

约束：保持少年面部和服装不变，滑板板面图案不变，无新人物出现。
```

## 参数

- 模式：T2V
- 时长：5s
- 比例：16:9 或 2.39:1
- 分辨率：1080p（动作场景 1080p 够用，4K 在快速运动中区别不大，反而增加生成负担）

## 为什么这么写

**为什么用跟随式？** 滑板场景的核心是"速度感"——观众要觉得自己在跟着滑。跟随式 = 镜头和主体同速运动，观众的身体跟着走，不是站在外面看。如果改成固定镜头拍滑板，就变成了"看别人滑"，沉浸感差一个量级。

**为什么显式写了"与滑板保持同一速度"？** 不写这句话，模型倾向于自由发挥镜头速度——有时候比滑板快，有时候慢，看起来像镜头在"犹豫"（经验观察）。显式声明"同速"是跟随式不翻车的关键。

**为什么加了时间轴三层？** 动作场景需要精确控制节奏。状态层告诉模型"从匀速到加速到急停"的变化轨迹；运动层告诉模型身体姿态怎么跟着变；节奏层告诉模型声音什么时候升级、什么时候停。三层叠加 = 一个有节奏感的动作序列，而不是一段"有人在滑"的随机运动。完整的三层模型语法见 [15-时间轴语法](../15-timeline-syntax.md)。

**为什么用 ▂▃▅▇▁ 情绪曲线？** 这条曲线的意思是"渐进到顶然后急停"。对应滑板的节奏：慢慢加速 → 最快 → 突然刹车。声音设计跟着这条曲线走——轮子声从低沉到尖锐到安静。观众的情绪被声音带着走。

**为什么不用 4K？** 实测下来，快速运动场景中 4K 和 1080p 的视觉差异很小（因为画面一直在动，细节本来就看不清），但 4K 的生成负担更大，翻车概率更高。1080p 是动作场景的甜点分辨率。

## 踩过的坑

第一次生成的时候，少年滑着滑着人脸变了——从亚洲面孔变成了欧美面孔。动作剧烈 + 侧面角度 + 夕阳逆光，三个因素叠加导致身份漂移。

**修复：** 在约束里加了"保持少年面部不变"。但说实话，这只能降低概率，不能完全解决。更稳的方案是用 I2V 模式——先给一张少年的参考图，让模型锁死身份，再写动作 prompt。

另一个坑：背景"路灯和建筑向身后匀速掠过"这句话，第一次没写。结果背景完全静止，看起来像在绿幕前面滑。跟随式的背景必须有运动感——哪怕只是一句"路灯掠过"，也能让速度感翻倍。
