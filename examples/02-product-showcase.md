# 案例 2：产品展示（定锚式）

## 场景

一瓶精酿啤酒的产品广告——瓶子不动，画面要稳，只有冷凝水和光线在变。

## Prompt

```
一瓶精酿啤酒放在深色花岗岩台面上，瓶身冷凝水珠缓慢滑落，在瓶底汇成一小滩水渍。
镜头：近景，产品四分之三角度，锁定三脚架，无运动。
光线：主光从左上方 45 度打入，色温 5200K，瓶身右侧形成一条窄高光带。
背景纯黑，无环境反射。
声音：安静，只有冷凝水珠落在石面上的极细微"嗒"声。
约束：保持瓶身形状、标签文字、瓶盖颜色、液面高度完全不变。
```

## 参数

- 模式：T2V（或 I2V 保持模式 + 产品照片首帧）
- 时长：5s
- 比例：9:16（竖版社交媒体）或 16:9（横版官网）
- 分辨率：4K

## 为什么这么写

**为什么用定锚式？** 产品广告的第一原则是"产品不能变"。标签上的字不能歪，瓶子形状不能扭，液面高度不能变。定锚式 = 主体不动 + 画面稳 + 只有一个微变化（冷凝水），是最安全的产品展示结构。

**为什么镜头锁定不运动？** 产品广告一旦镜头动了，透视关系就变，瓶子的形状会跟着变。实测下来，锁定三脚架 + 四分之三角度出来的效果最稳定。环绕运镜看着酷，但 logo 变形概率极高——除非你用 I2V 模式锁首帧。

**为什么只写了一个变化（冷凝水）？** 这是定锚式的核心纪律：一个主体 = 一个动作。你写了"冷凝水滑落 + 瓶身旋转 + 光线扫过"，模型同时处理三个变化，大概率崩。想要更多变化？拆成多镜头，每个镜头一个变化。

**为什么约束里写了"液面高度"？** 实测发现，如果不显式约束液面，模型在生成过程中会让啤酒液面微微下降——因为冷凝水在"消耗"。这种细节不写约束，翻车了都不知道为什么。

## 踩过的坑

标签文字。第一次没在约束里写"标签文字"，生成出来标签上的英文字母全变成了乱码——像外星文。可灵目前不擅长渲染精确文字，所以策略是：约束里锁死"标签文字不变"，然后祈祷。如果还是崩了，后期 PS 贴标签是最稳的方案。

另一个坑：背景"纯黑"我写了两遍（"背景纯黑" + "无环境反射"），因为如果不强调"无环境反射"，模型会在瓶身上映出一些莫名其妙的环境——可能是训练数据里其他产品广告的残留。
