# Before / After：导演引擎的价值

> "Direct the model, don't tweak pixels."
> 导演模型，而不是调像素。

---

## 方法论简介

大多数人写 AI 视频 prompt 的方式是**堆叠形容词**："cinematic, beautiful, 4k, epic, masterpiece"。这些词描述的是你对结果的*愿望*，而不是产生结果的*原因*。摄影机、麦克风、测光表都检测不到"epic"。

导演引擎（Director Engine）的做法相反：先回答五个导演问题——**功能（Function）、转折（Turn）、视角（Perspective）、权力（Power）、潜台词（Subtext）**——再从答案中推导出具体的技术选择。

**Prompt 公式：**

```
[主体 + 动作] + [镜头设置] + [光线变化] + [声音] + [约束]
```

下面 5 组对比展示：同一创意意图，从"标签沙拉"到"导演简报"的差距。

---

## 1. 产品广告 — 护肤品揭示

### Before

```
Beautiful cinematic product shot of a luxury skincare bottle, 4k,
ultra detailed, premium feel, epic lighting
```

### After

```
一只磨砂玻璃精华瓶从黑色亚克力台面下方缓缓升起，瓶身凝结着细密水珠。
镜头：微距，低角度 15° 仰拍，固定机位，瓶身升至画面中央时停止。
光线：单侧柔光箱从左后方 45° 打入，瓶身右侧形成一条窄高光带；
背景纯黑，无环境光溢出。
声音：一声清脆的玻璃轻叩，随后静默。
约束：无文字，无水印，无手部出现，背景无杂物。
```

### 为什么有效

"Premium feel" 无法被渲染；但"磨砂玻璃 + 单侧柔光 + 窄高光带"是可以被执行的物理指令。揭示类镜头的核心是**先隐藏再揭露**——瓶子从台面下方升起就是那个"揭示动作"，比静态摆拍多了一个节拍。

---

## 2. 短剧场景 — 她发现了背叛

### Before

```
Emotional cinematic scene, a woman crying in the rain, heartbreaking,
masterpiece, dramatic
```

### After

```
一个女人站在公寓门口，手里攥着另一部手机，屏幕亮光照亮她的下巴。
她的拇指悬停在屏幕上方，没有按下。
镜头：中近景，平视，85mm 长焦压缩背景，缓慢推进至近景（脸部）。
光线：走廊顶灯冷白 5600K 从上方打下，眼窝形成阴影；
手机屏幕暖光从下方补亮嘴唇，形成冷暖撕裂。
声音：走廊日光灯电流嗡鸣，远处电梯到达的"叮"一声。
约束：无台词，无配乐，雨声不出现（场景在室内走廊）。
```

### 为什么有效

导演五问的回答：功能 = 转折（信任→怀疑），视角 = 她的内心，潜台词 = "她已经知道了，但还没有承认"。"拇指悬停"这个微动作比"crying in the rain"精确十倍——它演的是*决定前的凝固*，而不是情绪的泛化表达。长焦压缩 + 缓推 = 观众的身体在被拉近她的内心。

## 3. 美食视频 — 一碗面的英雄镜头

### Before

```
Delicious food photography, amazing noodles, mouth-watering, 8k,
professional
```

### After

```
一双竹筷从碗中挑起面条，面条表面裹着琥珀色酱汁，
三缕蒸汽从面条缝隙中升起，在逆光中呈半透明白色。
镜头：特写，俯拍 30°，固定机位；筷子提起面条时镜头微微上摇跟随。
光线：后方窗户自然光（侧逆光），面条边缘形成金色轮廓光；
碗内阴影保留，不补光。
声音：面条被提起时酱汁滴落回汤面的"嗒"一声，随后是轻微的吸溜声。
约束：无文字，无手部以外的身体出现，桌面仅可见碗和筷子。
```

### 为什么有效

"Delicious" 和 "mouth-watering" 是观众的感受，不是画面指令。真正让食物镜头有食欲的是**物理细节**：酱汁的粘稠度、蒸汽在逆光中的透明度、滴落的瞬间。侧逆光勾勒轮廓 + 不补光保留阴影 = 立体感，这比"professional"具体一万倍。

## 4. 科幻场景 — 飞船接近行星

### Before

```
Epic sci-fi spaceship, breathtaking space scene, cinematic,
ultra realistic, volumetric lighting
```

### After

```
一艘 2 公里长的采矿船缓慢驶向画面右侧，船体表面布满焊接疤痕和
褪色的编号涂装。远处一颗气态行星占据画面右上方三分之一，
行星大气层呈现赭红色带状云纹。
镜头：极远景，飞船仅占画面 1/8；缓慢横移（左→右），
前景有一块漂浮碎片经过镜头前方形成遮挡。
光线：唯一光源为画面外的恒星（右上方），飞船朝向行星一侧为暗面，
仅引擎喷口发出冷蓝辉光；行星被照亮面过曝，形成剪影边缘。
声音：低频引擎震动（体感多于听觉），金属结构热胀冷缩的"嘎吱"声。
约束：无爆炸，无激光，无其他飞船，无文字 HUD。
```

### 为什么有效

"Epic" 和 "breathtaking" 是规模感的*结果*，不是*原因*。规模感来自**比例参照**：飞船仅占画面 1/8、前景碎片遮挡、2 公里长的具体数字。单一光源（恒星）+ 暗面 + 引擎辉光 = 真实的太空光照逻辑，比"volumetric lighting"这个标签稳定得多。

## 5. 人物肖像 — 老匠人工作中

### Before

```
Portrait of an old man, beautiful bokeh, cinematic color grading,
emotional, award-winning photography
```

### After

```
一位七十多岁的木匠坐在工作台前，右手握刨子推过一块榆木板，
刨花呈连续卷曲状从刨口翻出。他的左手拇指按住木板边缘，
指甲缝嵌着深色木屑。
镜头：中近景，平视，50mm 镜头 f/2.0，焦点在双手和刨花上，
面部自然虚化；固定机位，不运动。
光线：左侧一扇北向窗户，柔和散射光从画面左方打入，
在刨花卷曲处形成细小高光；右后方暗部不补光，保留轮廓。
声音：刨子推过木面的"嚓——"长声，刨花断裂的轻响，
远处收音机模糊的戏曲声。
约束：无文字，无滤镜颗粒感，面部不做特写，全程不抬头看镜头。
```

### 为什么有效

"Award-winning" 和 "emotional" 是评价，不是方向。这个镜头的意图是"让观众感受到时间沉淀在手里"——所以焦点给手和刨花，面部虚化；50mm f/2.0 的浅景深是*选择*而不是"beautiful bokeh"的许愿。声音设计（刨木声 + 远处收音机）用听觉暗示了数十年的日常重复，这比任何"cinematic color grading"都更能传递情感。

---

## 总结：从愿望到指令

| 维度 | Before 模式 | After 模式 |
|------|------------|-----------|
| 词汇 | 评价词（beautiful, epic, cinematic） | 物理描述（材质、角度、色温、距离） |
| 结构 | 逗号标签堆砌 | 公式化分段：主体→镜头→光线→声音→约束 |
| 情感传递 | 直接命名情感（heartbreaking） | 用身体动作 + 空间关系暗示情感 |
| 规模感 | 形容词（breathtaking） | 比例参照 + 前景遮挡 + 具体数字 |
| 质量保障 | 分辨率标签（4k, 8k） | 删除；质量是渲染设置，不是文字 |

**核心原则：如果一个词不能被摄影机、麦克风、测光表或秒表检测到，就改写它。**
