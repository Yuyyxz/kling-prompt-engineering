# 案例 4：美食特写（音画同步）

## 场景

一块牛排下锅的瞬间——重点是煎炸声和画面变化的精确对齐。

## Prompt

```
一块厚切肋眼牛排从画面上方落入热油中的铸铁锅，接触油面的瞬间溅起细密油花。
镜头：俯拍 45 度，近景，锁定。
光线：灶台侧面的暖色光，色温 3200K，牛排表面油脂在高温下开始冒细密气泡。

[0s-1s] 牛排接触油面——大量油花爆裂声，大油泡"啪啪"炸开，蒸汽从肉表面猛烈升起。
[1s-2s] 油花渐弱，牛排表面从粉红开始变为浅褐色，一只手持迷迭香在牛排上方轻晃，碎叶飘落。
[2s-3s] 一滴红酒从画面边缘滴入锅中，接触热铁的"嘶——"声，液体瞬间沸腾冒泡。
[3s-5s] 牛排表面形成完整焦壳，油脂在边缘微微冒烟，蒸汽在画面上方形成薄雾。

声音：
- 环境音层：抽油烟机低频嗡鸣（厨房底噪），灶火在锅底下燃烧的轻微呼呼声。
- 动作音效层：[0s-1s] 牛排入锅的爆裂煎炸声 → [1s-2s] 迷迭香碎叶落下的细碎"嚓"声 → [2s-3s] 红酒滴入热锅的"嘶——"声 → [3s-5s] 煎炸声趋于稳定，油脂冒泡的细密"滋滋"声。
- 情绪音乐层：无。烹饪场景的声音本身就是音乐——煎炸声有天然的节奏感，加音乐是画蛇添足。

约束：保持铸铁锅形状和颜色不变，无文字、无水印。
```

## 参数

- 模式：T2V
- 时长：5s
- 比例：9:16（竖版短视频）或 1:1（社交媒体）
- 分辨率：1080p

## 为什么这么写

**为什么用时间锚点 `[0s-1s]`？** 美食特写的灵魂是"声音和画面的同步"。如果牛排入锅的"嘶啦"声比画面慢了半秒，整个视频就假了。时间锚点告诉模型"在第几秒发生什么"，让声音和画面的对齐更可控。

**为什么声音分了三层？** 这是从 08-audio-guide 提炼的音画同步方法。环境音层（抽油烟机）给空间感——你一听就知道是厨房。动作音效层（煎炸、滴酒）给时间感——每个动作都有对应的声音。情绪音乐层我选了"无"——因为煎牛排的声音本身就够丰富了，加音乐会盖掉这些细节。

**为什么不用"美味""诱人"？** "美味"不是摄影机能拍到的东西（见 [09-反空话词典](../09-anti-slop.md)）。我写的是"表面从粉红变为浅褐色""油脂在边缘微微冒烟"——这些是"美味"的物理原因。观众看到焦壳形成、听到煎炸声，自己就会觉得"好吃"。你写"美味"反而什么都得不到。

**为什么时间分配是 0-1 / 1-2 / 2-3 / 3-5？** 第一个一秒给最剧烈的变化（入锅爆裂），然后逐渐减速。这是自然的食物烹饪节奏——最激烈的反应在接触的瞬间，之后趋于稳定。3-5s 给了两秒的"稳定态"，让画面有一个可以"停住"的结尾。

## 踩过的坑

第一次写的时候，声音部分只写了"煎炸声"三个字。结果模型生成的声音是均匀的"滋滋"底噪，完全没有入锅瞬间的爆裂感。

**修复：** 把声音拆成时间锚点对齐的动作音效。"[0s-1s] 牛排入锅的爆裂煎炸声"和"煎炸声"对模型来说是完全不同的指令——前者告诉它"这个声音在这个时间点爆发"，后者只给了一个模糊的方向。

另一个坑：红酒滴入锅中的镜头，第一次写的是"倒入红酒"。结果模型理解成"倒一整杯"，锅里全是红色液体。改成"一滴红酒从画面边缘滴入"才对了。量词很重要——"一滴"和"倒入"是完全不同的画面。
