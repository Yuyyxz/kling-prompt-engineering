# 案例 3：城市夜景空镜（揭示式）

## 场景

从一扇起雾的车窗内部，缓慢揭示出雨夜中的城市天际线——先模糊后清晰，制造"发现感"。

## Prompt

```
镜头从一辆停在路边的车内部开始。前挡风玻璃内侧蒙着一层薄雾，只能看到外面模糊的光斑——红的、白的、琥珀色的，在雾后面缓慢移动。
一只手从画面下方伸入，用手指在玻璃上擦出一道痕迹——透过这道清晰的缝隙，外面城市的轮廓逐渐显现：高楼、霓虹、湿漉漉的街道。
镜头：从车内仪表台高度拍摄，缓慢 push-in，穿过玻璃上的清晰缝隙，最终停在城市天际线的中远景。
光线：车外路灯和霓虹灯透过雾气形成漫射光斑，擦开的缝隙处光线锐利。
声音：车内沉闷的雨打车顶声、手指摩擦玻璃的吱嘎声、擦开后城市环境音突然变清晰——远处车流、行人脚步、一个红绿灯的滴滴声。
约束：无文字、无水印、无车内人物面部。
```

## 参数

- 模式：T2V
- 时长：5s（单镜头）或 10s（如果想让揭示过程更慢）
- 比例：2.39:1 变形宽银幕（电影感横构图）或 16:9
- 分辨率：4K

## 为什么这么写

**为什么用揭示式？** 城市夜景谁都会拍——但直接拍就是一个"壁纸"，没有叙事。揭示式的核心是"信息差"：观众先看到一个模糊的、不完整的东西，然后逐步看到全貌。这个"从不知道到知道"的过程，就是叙事。

**为什么遮挡元素是"起雾的车窗"？** 揭示式必须有一个物理遮挡。门、雾、手、物体——都行。我选车窗是因为：① 雾气是自然存在的遮挡，不需要"解释"为什么有雾；② 手擦玻璃这个动作给了观众一个"代理人"——是"有人"在揭示这个城市，不是镜头自己在动；③ 雾气→清晰的过渡在视觉上有天然的"对焦"效果。

**为什么声音要设计"突然变清晰"？** 这是揭示式在声音层的对应。雾在的时候，声音是闷的（物理遮挡 = 声音遮挡）。手擦开一道缝之后，城市环境音"突然变清晰"——和视觉的揭示同步。这种音画同步不需要时间轴语法也能实现，关键是让声音的"清晰度"跟随视觉的"清晰度"。

**为什么不用"赛博朋克"？** 因为"赛博朋克"是一个风格标签，不是一个可执行的描述。我写的是"霓虹灯透过雾气形成漫射光斑""湿漉漉的街道"——模型知道怎么渲染这些。你写"赛博朋克"，模型可能给你来一个紫蓝色调的科幻城市，跟你要的"真实城市雨夜"完全不是一回事。

## 踩过的坑

第一次生成的时候，手擦玻璃的动作太快——一秒就擦完了，揭示感没了。原因是 prompt 里没写速度。

**修复：** 加了"缓慢"和"逐渐显现"。对于揭示式，所有过渡动作都要写速度。"门打开"和"门缓慢打开"出来的节奏完全不同。经验上，模型对"缓慢""逐渐"这类速度词的理解比较准确（因版本而异）。
