# 案例 1：人物情绪特写（递进式）

## 场景

一个女人在深夜的便利店发现钱包丢了，从焦虑到释然——三镜头递进，从环境到人再到情绪。

## Prompt

```
镜头 1：远景，深夜的便利店，荧光灯把整条街道照成冷白色，玻璃门上贴着褪色的促销海报。
镜头缓慢推进。声音：冰柜压缩机嗡鸣、远处一辆车经过。

镜头 2：中景，一个穿灰色卫衣的女人站在货架前，翻遍口袋，手停在裤兜里不动了。
镜头：侧面平视，缓慢 push-in。声音：塑料袋摩擦声、手指在布料上摩擦的细微声。

镜头 3：近景，女人低头，肩膀微微下沉，然后呼出一口气，嘴角几乎不可见地松了一下。
镜头：锁定，85mm f/1.4 浅景深，焦点锁在眼睛。
声音：荧光灯电子嗡鸣，呼吸声，冰柜压缩机在远处咔嗒一声停了。
续接点：同一女人、同一灰色卫衣、荧光灯冷白色调保持一致、便利店货架背景不变。
```

## 参数

- 模式：T2V 多镜头
- 时长：每镜头 5s，共 ~15s
- 比例：16:9
- 分辨率：1080p

## 为什么这么写

**为什么用递进式？** 这个场景的核心是"情绪层层逼近"——观众要先看到环境（深夜便利店 = 孤独），再看到动作（翻口袋 = 出事了），最后看到表情（肩膀下沉 = 完了）。递进式天然适合这种"从远到近、从看到环境到感受到情绪"的结构。

**为什么镜头 3 用 85mm？** 85mm 是人像压缩的黄金焦距。背景会被压成一片色块，观众的注意力被强制锁定在眼睛上。如果用 24mm 拍近景，背景便利店货架会抢走注意力，情绪就散了。

**为什么声音在镜头 3 让冰柜停了？** 冰柜压缩机"咔嗒停了"这个细节不是随便加的。安静突然降临的时候，观众会感受到一种"释然"——她接受了这个事实。声音的消退 = 情绪的着陆。

**为什么不用"电影感""情绪感"？** 经验上这些词对模型没有明确指向（见 [09-反空话词典](../09-anti-slop.md)）。我写的是"荧光灯冷白色""85mm f/1.4 浅景深""肩膀微微下沉"——每个词都能被摄影机检测到。

## 踩过的坑

第一次写的时候，镜头 2 和镜头 3 之间没写"续接点"。结果生成的两个镜头光线方向完全不一样——镜头 2 荧光灯从上方打，镜头 3 突然变成侧面暖光。看起来像两个不同场景硬拼在一起。

**修复：** 在镜头 3 末尾加了"续接点：荧光灯冷白色调保持一致"。可灵在多镜头生成时，如果不显式声明续接锚点，它会在每个镜头重新"理解"光线。
