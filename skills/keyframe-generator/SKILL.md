# keyframe-generator — 分镜图生成

关键帧是把「画面长什么样」和「画面怎么动」拆开控制的手段。帧定得准，视频阶段就只剩运动问题；帧本身含糊，视频再贵也救不回来。

## 何时读 references

查精度分级标准读 `references/data.yaml` 的 `keyframe_precision`；空间/时间分离写法读 `spatial_prompt`、`temporal_prompt` 两节；重做判定读 `redo_rules`。先看 `references/sections.md` 定位行号。

## Workflow

1. 定这镜需要哪几帧：只有首帧、首尾帧、还是多关键帧。模型的关键帧上限看 `adapters/model_facts.yaml`（Kling 4.0 最多 10 个），不要按想象排帧数。
2. 每帧先写空间 prompt：只写这一帧静止时的构图、光线、主体状态，不写任何运动。
3. 帧与帧之间写时间 prompt：只写变化——谁动、往哪动、多久。空间和时间分开写，混写是漂移的头号来源。
4. 角色帧引用角色卡，appearance 逐字复用分镜里的角色卡文本，不要临场改写。
5. 按精度分级出图：定稿帧用高精度档，验证构图的草稿帧用低档，别全程一个档烧钱。
6. 尾帧描述单独存一份（`last_frame_description`），下一镜的首帧拿它对齐，这是跨镜连续性的锚。

## Gotchas

首帧里写了运动词（「正在奔跑」），图生视频会把姿态冻在半路。静态帧用状态词，不用进行时。

尾帧不是把首帧 prompt 改两个词。要按戏剧功能写这一镜结束时画面应该停在哪，情绪锚点先行。

关键帧越多不等于控制越强。帧间变化太碎，模型会在帧与帧之间硬跳；相邻关键帧之间只许一个主要变化，和单变量纪律同理。

## 规则

- 帧的编号跟素材编号走（见 material-numbering），不要自创命名。
- 重做关键帧只改出问题的一项，构图错改构图、光错改光，不要整帧重写。
- 生成参数（模型、seed、参考图）跟帧文件记在一起，复现不了的帧等于没有。
