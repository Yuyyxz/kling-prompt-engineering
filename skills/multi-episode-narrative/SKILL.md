# multi-episode-narrative — 多集连续叙事

从单镜头到多集连续剧，难的不是每集单独好看，是集与集之间不断线。断线一般断在三个地方：角色变脸、风格漂移、上一集结尾没人记下来。

## 何时读 references

拆集和写衔接时读 `references/four-act-and-sequence-state.md`，四幕拆法、尾帧记录格式、漂移处理都在里面。要看完整的八集示例和延长 prompt 范例，读 `references/data.yaml` 里的工作流示例。处理续写漂移时同时看根目录 `06-video-extension.md` 的接续门控。

## Workflow

1. 创作剧本，按四幕拆集：起、承、转、合，每幕对应哪些集先定好。
2. 每集写大纲，只写这一集的核心变化和结尾悬念。
3. 设计素材：角色、场景、道具按 C、S、P 编号固定，每角色至少 2 张参考图，角色卡外观描述逐字固定。
4. 每集生成时间轴格式分镜，风格前缀全剧统一，用同一份项目记录里的那一句，不要每集现编。
5. 第一集正常生成。从第二集开始用视频延长衔接，prompt 开头写延长语法并引用上一集视频。
6. 每集生成完立刻记录尾帧和序列状态：可见结束状态、开放运动方向、镜头阶段、光线阶段、声音阶段、连续性锁定、已完成节拍、预留节拍。记录没落盘，不许开下一集。

## Gotchas

续写不要拿上一集的输出图当新的身份参考滚下去，漂移会一集叠一集。身份锚点永远是最初的原始参考图，续写链长了要主动重新锚定。

计划和实际生成经常对不上。上一集实际结束在什么姿势、什么光线，下一集就从那个状态接，不要按大纲里预想的结尾硬接，画面会对不上。

一集塞完整部剧是新手最爱犯的。一集只讲一个核心变化，悬念留在结尾，下一集开头至少接住情感、悬念、视觉、动作里的两条。

风格、角色、配乐三条线断任何一条都先修再往下。批量生成完再返工，成本是逐集修的好几倍。

## 规则

- 延长 prompt 必须引用上一集视频，必须延续风格色调和配乐风格。
- 已完成的节拍在续集里排除，预留的节拍也排除，只做当前集的事。
- 素材编号全剧不复用不改号，角色换造型算新编号并在记录里注明。
