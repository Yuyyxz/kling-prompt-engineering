# kling-style-tags — 风格标签系统

把模糊的"我想要某种风格"翻译成可灵能执行的具体技术描述。

## 核心规则

风格标签不是形容词，是一组技术参数的缩写。每个标签展开为：色调 + 光比 + 镜头感 + 运动节奏 + 声音质感。

## 情绪风格（6 种）

## 组合公式

```
[导演风格] × [视觉风格] × [情绪] = 完整风格描述
```

示例：
- "王家卫 × 赛博朋克 × 孤独" → 长焦压缩的霓虹雨夜，一个身影在人群中缓慢移动，手持微晃，爵士钢琴混入电子底噪
- "是枝裕和 × 纪录片 × 治愈" → 自然光厨房，中景固定，母亲切菜的手，窗外鸟鸣，无配乐

## 使用规则

- 最多组合 3 个标签（1 导演 + 1 视觉 + 1 情绪）
- 组合后必须展开为具体技术参数，不能只写标签名
- 可灵对"水墨国风"和"东方美学"理解最好，优先使用
- 西方导演风格需要额外锚定：加真实摄影机型号或胶片型号
