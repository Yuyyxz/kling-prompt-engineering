# kling-storyboard — 分镜表输出

把导演意图转化为可执行的分镜表，每个镜头一行，可直接交给可灵生成。

## Workflow

1. 从用户输入中提取：故事/主题、时长、风格
2. 回答导演五问（整体层面）
3. 拆分为镜头序列（每个镜头 = 一个节拍 = 一个变化）
4. 为每个镜头填充 11 维信息
5. 输出分镜表

## 11 维格式

每个镜头必须包含：

| # | 维度 | 说明 |
|---|------|------|
| 1 | 镜号 | S01, S02, S03... |
| 2 | 时长 | 3s / 5s / 10s |
| 3 | 景别 | 极远景/远景/中景/近景/特写 |
| 4 | 角度 | 平视/仰视/俯视/荷兰角 |
| 5 | 运镜 | 固定/推进/拉远/跟随/环绕/手持 |
| 6 | 主体+动作 | 谁在做什么（一个动作） |
| 7 | 光源 | 具体光源 + 方向 + 色温 |
| 8 | 声音 | 环境音/音效/对白/音乐 |
| 9 | 转场 | 硬切/叠化/淡入淡出/匹配剪辑 |
| 10 | 约束 | 排除项 |
| 11 | 戏剧功能 | 引入/深化/转折/收束 |

## 输出模板

```markdown
# [项目名] 分镜表

风格：[风格描述]
画幅：[16:9 / 9:16 / 1:1]
总时长：[Xs]
镜头数：[N]

---

| 镜号 | 时长 | 景别 | 角度 | 运镜 | 主体+动作 | 光源 | 声音 | 转场 | 约束 | 功能 |
|------|------|------|------|------|-----------|------|------|------|------|------|
| S01 | 5s | 远景 | 平视 | 缓推 | ... | ... | ... | — | ... | 引入 |
| S02 | 3s | 近景 | 仰视 | 固定 | ... | ... | ... | 硬切 | ... | 深化 |
| S03 | 5s | 中景 | 平视 | 跟随 | ... | ... | ... | 硬切 | ... | 转折 |
| S04 | 3s | 特写 | 俯视 | 固定 | ... | ... | ... | 叠化 | ... | 收束 |
```

## 规则

- 每个镜头只有一个动作/变化
- 相邻镜头的景别必须有变化（不能连续两个中景）
- 光源必须在镜头间保持连续性（除非有动机的变化）
- 总时长 = 各镜头时长之和
- 15s 以内：最多 3-4 个镜头
- 30s：最多 6-8 个镜头
- 60s+：建议拆分为多集
